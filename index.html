Channel Manager

A private automation tool for operating my own YouTube channels.

In one line: it uploads videos to YouTube channels that belong to me, and reads their own statistics back so I can see what is working.

What it does

  • Uploads short videos to YouTube channels I own.
  • Schedules those uploads and manages their titles and descriptions.
  • Reads view counts, watch time and subscriber figures for my own channels, so I can check results and stop repeating what does not work.
  • Searches publicly available YouTube videos to find source material.

What it does not do

  • It has no user accounts, no sign-ups and no public interface.
  • It is not available to anyone else. There is no distribution channel.
  • It does not collect data from viewers, and it has no access to viewer personal information.
  • It does not read or write anything on a channel that is not mine.

Why YouTube access is requested

Uploading requires the youtube.upload permission, and reading my own channel analytics requires the youtube permission. Both are used only against channels I own.

Where things run

The tool runs on a private server I control. Sign-in credentials are stored there and are never transmitted anywhere else, sold, or shared with third parties.
